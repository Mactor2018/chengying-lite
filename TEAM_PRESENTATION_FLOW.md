## 10-Minute Demo Order

### 1. Dashboard

Narration:

CareBridge is a nursing home communication and care coordination platform. It brings resident profiles, family communication, staff scheduling, and daily care documentation into one role-aware workspace.

Show:

- Dashboard value proposition
- Four core modules
- Demo flow on the left side

### 2. Personnel & Resident Profiles

Route:

```text
/personnel
/residents
```

Narration:

The platform is resident-centered. Each resident is connected to family members, caregivers, nurses, supervisors, and doctors. This makes responsibilities clear and reduces communication gaps.

Show:

- Personnel Network graph
- Residents page
- One resident profile and assigned staff/family context

### 3. Communication & Service Inquiries

Route:

```text
/conversations
/service-inquiries
/conversation-detail
```

Narration:

Family messages are not isolated chats. CareBridge turns them into accountable conversations and service inquiries, so staff can track status, assignment, priority, and resolution.

Show:

- Conversation list
- Open a conversation detail
- Send one message
- Create or update a service inquiry

### 4. Schedule & Appointment Management

Route:

```text
/schedule
/appointment-requests
/schedule-analytics
```

Narration:

The schedule module coordinates daily care tasks, activities, clinical checks, and family visits. Staff can add, modify, complete, or delete schedule events while appointment requests move through review.

Show:

- Schedule board
- Add or complete a schedule event
- Appointment request review
- Schedule analytics

### 5. Care Records & Reports

Route:

```text
/care-records
/care-records/add
/care-records/chart
/reports
```

Narration:

Care records preserve structured nursing-home documentation. Staff can add, modify, soft delete, search, and analyze records. The audit trail supports accountability, and daily reports convert care data into family-readable summaries.

Show:

- Search care records
- Add or modify one care record
- Open Care Record Charts
- Open Daily Reports

### 6. Closing

Narration:

CareBridge improves transparency for families, coordination for staff, and operational visibility for nursing home managers. The system is designed around a single source of truth for every resident's care journey.

Show:

- Return to Dashboard
- Point to the unified navigation
